# UI-UX-Experiment 1
## Aim:

To understand the fundamentals of UI and UX design, differentiate between UI and UX using real-world examples, study the relationship between UI and UX in product design, and explore various UI/UX design tools.

## Algorithm:
1.Study the basic concepts of User Interface (UI) and User Experience (UX).
2.Analyze real-world applications and identify UI and UX features.
3.Compare UI and UX based on design, usability, and user interaction.
4.Observe how UI and UX work together in application development.
5.Explore popular UI/UX design tools such as Figma, Adobe XD, Sketch, and Canva.
6.Create simple interface prototypes using the tools.
7.Record observations and findings from the experiment.

## Result:

Thus, the fundamentals of UI and UX were successfully explored, the differences between them were understood using practical examples, the relationship between UI and UX was illustrated, and various UI/UX design tools were demonstrated successfully.
